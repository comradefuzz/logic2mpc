Прогон тестов: $ARGUMENTS

Запусти `.venv/bin/python -m pytest -q $ARGUMENTS` из корня проекта (полный набор идёт около трёх минут, запускай в фоне). Сообщи итог: сколько прошло, упало, пропущено. При падениях покажи имена тестов и суть ошибок, ничего не чини без просьбы.
