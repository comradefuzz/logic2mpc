Актуализация тестирования. Правила: `docs/testing.md`.

1. Запусти `.venv/bin/python scripts/tests_registry.py audit` в фоне (прогон идёт около двух минут).
2. Покажи находки: превышение бюджета full 150 с и smoke 15 с, тесты медленнее 2 с, пропущенные тесты и причины, ошибки реестра.
3. Сверь набор с целями проекта (CLAUDE.md) и оцени целесообразность тестов по группам: тесты снятых правил, дубли, тесты без пути к цели проекта. Оценка в реестр не записывается. Для каждой находки предложи решение: удалить, переписать, ускорить или оставить с причиной.
4. Ничего не удаляй и не правь без решения пользователя. После решения: удалённые тесты остаются строками `status: removed` с причиной удаления, остальные правки вносятся в `tests/registry.tsv`, затем `scripts/tests_registry.py check`.
