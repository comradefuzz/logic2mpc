# Logic → MPC Export Planner

**Перенесите песню из Logic Pro на Akai MPC Live 2 за вечер, а не за неделю.**

Ручной перенос выглядит так: часы нарезки стемов, раскладка сотен сэмплов по пэдам, повторное набивание нот в сетку. Планировщик делает это за вас. Вы указываете проект Logic и экспорт его дорожек, программа анализирует партии, режет дорожки на минимальный набор сэмплов, раскладывает их по пэдам, переносит ноты и собирает готовый проект `.xpj`. Остаётся скопировать его на SD-карту и играть.

> **Статус: публичное тестирование, версия 0.x.** Работает на реальных песнях, проверено на Live 2 с прошивкой 3.10. Интерфейс и формат плана ещё могут меняться. Находки и замечания приветствуются.

Подробно о целях и правилах: [CLAUDE.md](CLAUDE.md), алгоритм анализа: [docs/analysis.md](docs/analysis.md), известные проблемы: [docs/known-issues.md](docs/known-issues.md).

## Что получаете

- **Проект MPC целиком.** Один `.xpj` с сэмплами: драм-треки по группам вашего проекта (drums, bass, synth и так далее), 128 пэдов на трек, секвенция на каждый маркер Logic. Десктопное приложение MPC не нужно.
- **Минимум сэмплов вместо тысяч нарезок.** Лупы, одиночные удары, фразы и райзеры сводятся к осмысленному набору. Одинаковые звуки сливаются в один сэмпл, а потери записываются в отчёт.
- **План, который решаете вы.** Автоматика предлагает черновик, вы правите его в браузере: объединяете и разделяете группы, переносите дорожки, сливаете варианты, прослушиваете сэмплы. Каждое решение помнит, кто его принял (правило или вы), и какова уверенность.
- **Честный отчёт о потерях.** Перевод из философии Logic в философию MPC всегда что-то отбрасывает. Программа говорит что именно, а не делает вид, что копия точная.
- **Готово к живой игре.** Правильные режимы пэдов (One Shot и Note On), общие mute group для вариантов одной дорожки, цвета треков и пэдов по дорожкам Logic.

## Как это работает

1. Вы указываете проект Logic (`.logicx`) и папку с экспортом дорожек.
2. Программа читает из проекта структуру: папки (Track Stacks), регионы, ноты, темп, маркеры.
3. Анализ режет каждую дорожку по правилам (ниже) и предлагает план.
4. Вы правите план в браузере и подтверждаете его.
5. Экспорт собирает проект MPC. Вы копируете его на SD-карту и открываете на Live 2.

Аудио никуда не уходит: всё считается локально на вашем Mac.

## Какие стратегии анализа уже реализованы

Анализ выбирает стратегию для каждой дорожки сам, по данным проекта, а не по названию. Каждая стратегия опирается на правило из [docs/analysis.md](docs/analysis.md).

### Аудиодорожки

- **Одиночные удары** (кик, клэп, хэт): каждый регион это один звук, одинаковые сливаются в один сэмпл. Из 320 ударов получается один сэмпл и 320 нот.
- **Склейка регионов.** Регионы, стоящие встык на таймлайне и в файле, считаются одним звуком: райзер, порезанный на куски, снова становится цельным.
- **Цельные звуки** (свипы, импакты, даунлифтеры): сэмпл берётся целиком, без ложной нарезки по атакам.
- **Лупы.** Если в Logic включён Loop, длина фрагмента равна длине лупа (1, 2, 4, 8 или 16 тактов), каждый проход становится нотой.
- **Звуки в регионах** (филлы, брейки, фразы): каждый регион это звук, одинаковые определяются по данным проекта и по сравнению формы волны и спектра.
- **Универсальное разрезание по сетке** для сложных партий: окна в 1, 2, 4 и 8 тактов, сравнение звука, выбор образца, ближайшего к остальным, и деление на минимум фрагментов.
- **Чистый старт.** Ударные образцы начинаются точно со звука, без паузы перед ним, нота ставится в тик атаки.

### MIDI-дорожки

- **Повторы ищутся по нотам, а не по звуку.** Один и тот же синт на одних нотах звучит каждый раз по-разному, поэтому сравнивается рисунок: время и высота нот.
- **Поиск периода и начала цикла** (1, 2, 4, 8 тактов) по регионам, затем по ядру нот для длинных или разных регионов.
- **Партии без цикла** режутся от начала региона до конца звука.
- **Образец фразы** выбирается как проход, где она сыграна целиком, недоигранные проходы и проходы вне сетки учитываются отдельно.
- **Кейгруппа вручную.** Партию в экспорте можно превратить в цикл-сэмпл, а кейгруппу на MPC вы делаете сами, если захотите.

### Решительность

Один ползунок задаёт, сколько вариантов фрагмента оставить: от нескольких вариантов до минимума в крайнем правом положении. Уверенность вычисляется для каждого решения отдельно.

### Перенос нот и структуры

- Каждый маркер Logic становится секвенцией MPC с тем же именем и длиной.
- Громкость ударов переводится в velocity.
- Режим пэда (One Shot или Note On) выбирается по длине образца и тому, доигрывается ли он до конца секции.
- Варианты одной дорожки получают общую mute group и один цвет, как регионы одной дорожки в Logic.
- Имена сэмплов получают понятный вид `КОД_ГРУППА_Имя_NN`, кириллица транслитерируется.

### Правка плана

Объединение и разделение групп, перенос дорожки между группами, слияние вариантов в один пэд, переименование. Каждая правка записывается новой версией плана, прежняя не меняется.

## Планы

Пока вне версии 0: автоподбор плагинного инструмента по тембру, слои на пэде с циклическим и случайным воспроизведением вариантов, сборка поверх вашего шаблона MPC, нативная оболочка приложения.

## Установка

macOS, Python 3.10+.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Запуск

Все команды запускаются из корня репозитория. Пути к проекту Logic, экспорту и результату задаются аргументами.

### Интерфейс

Стартовый экран, анализ, правка плана в браузере и сборка проекта. Открывает страницу на `http://127.0.0.1:8765/`, сервер слушает только локальный адрес.

```bash
.venv/bin/python -m logic2mpc ui
```

Без аргументов открывается стартовый экран: выберите проект Logic (`.logicx`) и папку с экспортом дорожек, проверьте код песни и нажмите «Анализировать». План появится в папке `plan/` рядом с экспортом, дальше откроется редактор.

Чтобы сразу открыть готовый план, передайте папку версии или папку с версиями (откроется последняя):

```bash
.venv/bin/python -m logic2mpc ui test-projects/exports/elated/plan
```

После сборки открывается экран «Проект»: треки с раскладкой пэдов по банкам, секвенции, число сэмплов и размер, прочитанные из собранного `.xpj`.

Папку проекта MPC и его имя выбирают в панели «Экспорт». Необязательные аргументы:

- `--out <папка>` и `--name <имя>`: начальные значения панели «Экспорт»;
- `--port <N>`: порт, по умолчанию 8765;
- `--no-browser`: не открывать браузер сам.

Сервер читает код при запуске. После обновления репозитория остановите его (Ctrl+C) и запустите заново.

### Командная строка

```bash
.venv/bin/python -m logic2mpc analyze <проект.logicx> <папка экспорта> --groups <groups.json> --out <папка плана>
.venv/bin/python -m logic2mpc confirm <папка версии плана>
.venv/bin/python -m logic2mpc build <папка версии плана> --out <папка проекта> --name <имя проекта>
```

- `analyze` режет дорожки, пишет новую версию плана (`vN`) с сэмплами и отчётом.
- `confirm` записывает подтверждение конкретного плана.
- `build` собирает проект `.xpj` и папку `<имя>_[ProjectData]`, отказывается без подтверждения текущего плана.

Пример файла групп: [examples/elated.groups.json](examples/elated.groups.json).

## Тесты

```bash

```

Часть сценариев работает на реальном проекте и пропускается без переменных окружения, см. `tests/test_real_project.py`.

## Загрузка на Live 2

Скопируйте на SD-карту `<имя>.xpj` и папку `<имя>_[ProjectData]` вместе, откройте проект на устройстве.
