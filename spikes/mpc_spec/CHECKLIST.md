# Чек-лист спайка 9, раунд 1

Один заход на Live 2, до 30 минут. Скопируй на SD всю папку `test-projects/mpc/spike9/`, имена не меняй. Открой каждый проект, запусти пэды и секвенцию, заполни таблицу. Если проект не открылся, запиши текст ошибки и иди дальше. Кейсы собраны `cases.py`, на каждый одно изменение исходного проекта. Всего 24.

| Проект | Что проверить | Результат |
|---|---|---|
| `Z01 no-service` | Открылся ли проект без служебных треков Out, Submix, Return; что показал Live 2; виден ли `Drum 001` | |

| `Z03 no-submix-return` | Открылся ли проект без Submix и Return при наличии Out | |
| `R01 no-mixer` | Открылся ли проект без ключа `mixer`; работает ли микшер | |
| `R02 no-scene` | Открылся ли проект без `scene` | |
| `R03 no-songs` | Открылся ли проект без `songs`; открывается ли Song Mode | |

| `Q01 min-clip` | Открылся ли проект, где у клипов убраны постоянные поля; звучат ли ноты | |
| `Q02 min-event` | Открылся ли проект, где у нот убраны постоянные поля; звучат ли ноты | |
| `Q03 min-sample` | Открылся ли проект, где у записей сэмплов убраны постоянные поля; находит ли Live 2 файлы | |
| `Q04 min-sequence` | Открылся ли проект, где у секвенции убраны постоянные поля; длина и темп на месте | |
