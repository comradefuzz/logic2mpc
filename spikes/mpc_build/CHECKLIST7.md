# Чек-лист спайка 7

Один заход на Live 2, около 20–25 минут. Скопируй на SD всю папку `test-projects/mpc/spike7/`, имена не меняй. Открой каждый проект, запусти секвенцию, заполни таблицу. Если проект не открылся, запиши ошибку и иди дальше.

| Проект | Что проверить | Результат |
|---|---|---|
| `A01 audio` | Длинный луп на A02 звучит целиком | |
| `A02 formats` | Сэмплы из экспорта Logic на A02 (стерео) и A03 (моно) | |
| `D01 pads16` | 16 пэдов, разные сэмплы, ноты по четвертям | |
| `D02 pads64` | 64 пэда, 4 банка заполнены | |
| `D03 pads128` | 128 пэдов, заполнены ли все банки, звучит ли хвост | |
| `E01 missing` | Что сказал Live 2 про сэмпл без файла, открылся ли проект | |
| `F01 full` | Порядок `HANDS`, `Drum 001`, `Bass`, `Synth`, всё звучит | |
| `G01 merge` | `Drum 001` и `Bass` идут в Submix 1 | |
| `K01 root0` | Трек `Bass`: сэмпл на всю клавиатуру, высоты меняются? | |
| `K02 root36` | То же, какая нота звучит как исходный сэмпл | |
| `K03 root36track` | То же, отличается ли от `K02` | |
| `K04 mono` | То же, ноты обрывают друг друга | |
| `M01 midi` | Трек `Synth` с 8 нотами, инструмента нет, выход не задан | |
| `M02 mute` | Трек `Muted` выключен, клип `Clip off` не слышен, ноты на месте | |
| `S01 sections` | Две секвенции `Verse` и `Chorus` | |
| `S02 tracks` | `Drum 002` в обеих секвенциях со своими нотами | |
| `S03 meter` | С такта 3 размер 3/4 | |
| `V01 velocity` | Пэд A02 чередует два сэмпла по скорости нажатия | |

## Образец для Song Mode и темпа

В файлах нет примера, поэтому один образец нужен с железа: в любом проекте с двумя секвенциями собери Song из них в нужном порядке и поставь смену темпа внутри одной секвенции. Сохрани как `Sample Song` и положи в `test-projects/mpc/spike7/`.
