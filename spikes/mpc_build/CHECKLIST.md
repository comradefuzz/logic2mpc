# Чек-лист спайка 8

Один заход на Live 2, около 15 минут. На компьютер вернуться нужно один раз, в конце.

## 1. Подготовка

Скопируй на SD всю папку `test-projects/mpc/spike8/` вместе с папками `_[ProjectData]`. Имена не меняй.

## 2. Проверка

Открой каждый проект, запусти секвенцию и заполни таблицу. Если проект не открылся, запиши текст ошибки и иди к следующему: кейсы не зависят друг от друга.

| Проект | Открылся | Что проверить | Результат |
|---|---|---|---|
| `T01 same` | | Одна нота на доле 1, как в `Spike4 A` | |
| `T02 note` | | Нота на доле 3 | |
| `T03 notes` | | 8 нот восьмыми, чётные тише | |
| `T04 pad` | | Пэды A01 и A02 звучат разными сэмплами, 8 четвертей по очереди | |
| `T05 track` | | Два драм-трека, `Drum 002` играет между долями | |
| `T06 keygroup` | | Трек `LD True Survivor` звучит на ноте 60 | |
| `T07 plugin` | | Трек `BS Tube`, плагин Sub Factory звучит | |
| `T08 midi` | | Трек `MIDI Minilogue`, какой порт показан, идут ли ноты в Minilogue | |
| `T09 tempo` | | Темп 97, две секвенции | |
| `T10 full` | | Порядок треков `HANDS`, `Drums`, `LD True Survivor`, `BS Tube`, `MIDI Minilogue`, темп 97 | |

## 3. Пересохранение

Открой `T10 full`, выбери `Project As`, имя `T10 resaved`. Закрой и открой снова. Если `T10` не открылся, пересохрани последний проект, который открылся.

## 4. Готово

Скопируй `T10 resaved.xpj` с папкой `_[ProjectData]` в `test-projects/mpc/spike8/` и пришли таблицу.
