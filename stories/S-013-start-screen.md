## Стори

в начале флоу нужен экран выбора проекта Logic, папки с экспортом. Потом текущий редактор. Группы строить по папкам Logic с кодами по умолчанию, которые правятся в редакторе.

## Анализ

**Что требуется.** Первый экран: пользователь выбирает проект Logic и папку с экспортом, нажимает «Анализировать», видит ход, попадает в редактор (S-011) на новой версии. Файл групп вручную больше не нужен.

**Что уже есть.** `app.analyze(project, export, groups_file, out, decisiveness)` делает всё, кроме файла групп. Группы проекта это папки Logic (Track Stacks), их читает `adapters/logic.py` (`track.group`). Файл групп сейчас задаёт код и способ: `examples/elated.groups.json`. Анализ идёт заметное время, прогресс по дорожкам печатается в консоль.

**Решение пользователя.** Группы строятся по папкам Logic, код группы выбирается по умолчанию и правится в редакторе. Правка кода группы в редакторе в S-011 не входила, она входит сюда.

**Что неясно.** Правила кода по умолчанию и место результата, см. вопросы.

### Вопросы

- [x] Код по умолчанию по таблице имён подходит: `Drums`→`DR`, `Bass`→`BS`, `Synth`/`Lead`/`Keys`→`SY`, `FX`→`FX`, `Vocal`→`VX`, `Guitar`→`GT`, прочие первые две буквы большими
- [x] Результат анализа в папке `plan/` рядом с экспортом, создаётся сама
- [x] Дорожки вне папок Logic складываются в группу «Прочее», отказа нет

**Уточнения при разборе плана.**

- Код группы «Прочее» `OT`, способ `drum`.
- Код песни (`ELA`) на экране предлагается по имени проекта: часть после ` - `, если она есть, иначе всё имя, три первые буквы латиницей большими, поле правится.
- Имя проекта MPC по умолчанию берётся из имени проекта Logic, правится в панели «Экспорт» (S-011).
- Выбор проекта Logic системным окном (`.logicx` это пакет, окно выбирает его как файл) и поле ввода пути запасом.
- `ui <папка>`: папка с `plan.json` открывается как версия, папка с версиями `vN` открывается на последней, без аргумента стартовый экран.

## План

Порядок: правило, тест, код. Новое правило в `docs/analysis.md`.

1. **Правило `AN-071` (группы по умолчанию)**, статус `гипотеза`: группа плана это папка Logic, код по таблице имён, способ `drum`, дорожки вне папок это группа «Прочее» с кодом `OT`, код песни по имени проекта.
2. **Ядро `core/groups.py`.** `default_groups(names)`, `song_code(project_name)`. Чистые функции.
3. **Правка кода группы** в `core/edit.py`: операция `set_code`, два заглавных латинских символа, имена сэмплов группы переименовываются по тем же правилам, что при переносе. Поле кода в заголовке группы в редакторе.
4. **Сценарий `app.py`.** `analyze` принимает код песни и работает без файла групп (файл остаётся для CLI), дорожки вне папок идут в «Прочее» (раньше отказ), обратный вызов прогресса по дорожкам. `inspect_project(project, export)`: число дорожек и групп, дорожки без файла экспорта, код песни по умолчанию. `find_version(папка)`. `Workspace`: текущая сессия, фоновый анализ с прогрессом, один анализ за раз.
5. **Сервер.** `GET /api/state` без сессии отдаёт `mode: start`. `POST /api/pick-logic`, `POST /api/pick-export` (системные окна), `POST /api/inspect`, `POST /api/analyze`, `GET /api/progress`. По окончании анализа открывается сессия редактора на новой версии. Те же `Host` и `Origin`, правки и сборка без сессии отказ.
6. **Страница.** Стартовый экран: проект Logic и папка экспорта (кнопка и поле), код песни, проверка (дорожек, групп, нет файла экспорта у дорожек), «Анализировать», индикатор по дорожкам, переход в редактор. Код группы правится в заголовке группы.
7. **Команда `ui`.** Аргумент версии необязателен, `ui <папка плана>` берёт последнюю версию.
8. **Прогон на Elated.** С нуля на копии в `test-projects/copies`, сверка с `v3` по числу кусков (74) и группам.

**Отклонения от плана и изменения тестов:**

- Тест `test_analyze_track_outside_stack_is_error` заменён на `test_an071_track_outside_stack_goes_to_other_group`: поведение изменилось по решению пользователя (дорожки вне папок идут в «Прочее»), старый тест был верен прежнему правилу, код не подгонялся.
- `analyze` больше не создаёт пустые группы: группа из файла групп без дорожек в план не попадает. Прежние планы это не затрагивает, в Elated все группы заняты.
- Порядок групп в плане при анализе без файла групп идёт по папкам Logic, а не по файлу `examples/elated.groups.json`: `Synth`, `Drums`, `Bass`, `Lead`, `FX`, `Keys`. Состав и число кусков (74) те же.
- Стартовый экран и редактор живут в одной странице, переключение по `mode` в состоянии сервера.
- Прогон на копии Elated (ссылки на экспорт во временной папке, анализ без файла групп): 58 дорожек, 6 групп, 74 куска, `Stereo Out` без звука в план не входит, код `ELA`. Окна выбора проекта и папки в живую не открывались.

- Дополнение при приёмке: из редактора можно вернуться на стартовый экран кнопкой «← К выбору проекта» (`POST /api/close`). Несохранённые правки сбрасываются только после второго нажатия, во время сборки и анализа выход отказ 409, версии на диске остаются. Тесты `test_close_*`.
- Дополнение при приёмке: `analyze` больше не печатает названия дорожек в терминал (интерфейс показывает ход на экране), команда `analyze` в CLI печатает `[N/M] дорожка` через обратный вызов прогресса. Тест `test_analyze_prints_nothing_to_terminal`.

Не входит: анализ нескольких песен, настройка решительности в экране (остаётся значением по умолчанию), автоматический выбор способа группы, плагинные и MIDI-треки.

## Итог ревью

Один раунд, субагент `reviewer`. 7 замечаний, исправлены 1, 2, 4, 5, замечания 3, 6, 7 учтены.

- Код песни приходил со страницы без проверки и шёл в имена файлов: `../../X` писал WAV за пределы версии. Теперь три заглавные латинские буквы проверяются в `analyze` и на сервере, тест добавлен.
- `POST /api/analyze` при открытом плане подменял сессию и терял несохранённые правки: теперь отказ 409 «план уже открыт», тест добавлен.
- Проект без дорожек со звуком создавал пустой план: теперь отказ «в проекте нет дорожек со звуком».
- Тест эквивалентности анализа без файла групп и с файлом был половинным: добавлено полное сравнение планов, плюс тест, что пустая группа из файла в план не входит.
- Путь экспорта со страницы допускает запись `plan/vN` в любую существующую папку, где есть файлы `NN_*.wav`: для локального однопользовательского приложения принято, записано.
- Папка Logic с именем «Прочее» сольётся с группой для дорожек вне папок: описано в `AN-071`.

Правки после ревью отдельным раундом не проверялись, автотесты зелёные.
