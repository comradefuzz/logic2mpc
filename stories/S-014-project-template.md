## Стори

Экспорт по желанию собирает проект поверх шаблона пользователя: проекта MPC с основным роутингом, служебными треками и заранее созданными пустыми треками. Без шаблона экспорт работает как сейчас, по описанию формата. Убрать создание пустого HANDS из экспорта в эту стори не входит: это [S-021](S-021-no-hands-track.md).

## Анализ

**Как сейчас.** После [S-018](S-018-xpj-from-spec.md) [xpj.py](../logic2mpc/adapters/xpj.py) строит проект целиком из описания формата: корень из десяти ключей, треки групп, секвенции по секциям, без служебных треков (потеря «нет Submix и Return», MPC-112). Проект на Live 2 открывается, но в MIX у него нет Submix и Return, и добавить их из интерфейса нельзя. Шаблон пользователя, сохранённый самим Live 2, содержит служебные треки и роутинг, поэтому проект поверх него получает их без потери.

**Что известно о формате.**
- Служебные треки Out, Submix, Return есть в любом проекте, сохранённом Live 2, удалить их нельзя (MPC-110).
- Проект без них открывается (MPC-112), корень сводится к десяти ключам (MPC-113); значит поверх шаблона нужно менять только `tracks`, `sequences`, `samples` и темп.
- Новый трек вставляется перед служебными, клип нового трека добавляется в каждую секвенцию (MPC-023).
- Копия объекта из чужого проекта приносит скрытое состояние (`recordArm`, MPC-111), поэтому треки групп создаются из описания, а не копируются из шаблона.
- Совместимость шаблонов других версий прошивки не проверялась (versions.md).

**Не известно.** Нужны ли правки записей служебных треков в `trackClipMaps` секвенций, когда экспорт добавляет секвенции в шаблон: проверяется на Live 2.

**Принято при анализе, подтвердить при `/approve`.**
- Шаблон необязателен: параметр `template` (путь к `.xpj`). Без него поведение прежнее.
- Шаблон проверяется до записи: читается, расширение `.xpj`, есть служебные треки (тип 7 и выше), иначе `ValueError`.
- Все треки шаблона (пользовательские и служебные), их программы, роутинг и остальные ключи корня остаются как есть. Треки групп вставляются после пользовательских треков шаблона и перед служебными.
- Секвенции шаблона заменяются секвенциями по секциям плана. Ноты и клипы предустановленных треков в них не переходят, клипы этих треков в новых секвенциях пустые.
- `samples` шаблона не обнуляется, сэмплы групп добавляются.
- Имя группы, совпавшее после транслитерации с именем трека шаблона, отказывает сборку до записи: клипы ищутся по имени трека (MPC-024).
- Темп плана записывается в `masterTempo` и секвенции, остальные настройки шаблона не меняются. `currentTrackIndex` шаблона не меняется.
- Новые треки получают `recordArm` false всегда (в проекте рабочим остаётся трек шаблона), роутинг новых треков как в описании формата.
- Версия прошивки шаблона не проверяется.
- Потеря «нет служебных треков» при шаблоне не записывается.
- Параметр входит в контракт экспортёра как опция, схема плана не меняется. В интерфейсе поля шаблона нет, только командная строка.

## План

1. **Сборка поверх шаблона.** `xpj.export_project(..., template=None)`: при `template` корень берётся из шаблона целиком, `tracks` дополняются треками групп перед служебными, `sequences` заменяются секциями плана (клипы для всех треков шаблона пустые, для треков групп с нотами), `samples` дополняются, темп обновляется. Загрузка и проверка шаблона вынесены в `load_template`.
2. **Проверки.** Шаблон не читается, не `.xpj` или без служебных треков: `ValueError`; имя группы совпало с треком шаблона: `ValueError`; всё до записи, папка вывода не создаётся.
3. **Вызовы.** `app.build(..., template=None)` и `build_result`, `build --template <путь>`, `ui --template` не вводится.
4. **Фикстура.** `tests/fixtures/template.xpj`: проект Live 2 (копия `Empty.xpj` с добавленным пустым драм-треком `Minilogue`), в пакет не входит.
5. **Документы.** `docs/contracts/xpj-export.md` (опция `template`, поведение), CLAUDE.md («Вне первой версии»: убрать пункт о шаблоне).

Затрагиваются: `logic2mpc/adapters/xpj.py`, `logic2mpc/app.py`, `logic2mpc/__main__.py`, `docs/contracts/xpj-export.md`, `CLAUDE.md`, `tests/test_xpj_spec.py`, новая `tests/fixtures/template.xpj`.

Не входит: создание проекта с нуля без служебных треков (уже есть), удаление HANDS ([S-021](S-021-no-hands-track.md)), сопоставление группы с предустановленным треком по имени, перенос нот шаблона, проверка версии прошивки, поле шаблона в интерфейсе.
