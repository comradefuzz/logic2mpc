## Стори

убрать принудительное создание Hands как неоправданную привязку к частному случаю. Вместо этого заложить  возможность  использования шаблонного проекта в формате MPC (содержит основной роутинг и заранее созданные пустые треки, новые треки в ходе экспорта создаются программно)

## Анализ

**Приоритет и блокировка.** Функционал COULD, отдельная стори. Блокирована [S-018](S-018-xpj-from-spec.md): сборка по описанию формата (из результата S-015, `export.tsv`) должна появиться раньше, шаблон пользователя добавляется поверх неё. Разблокировать после приёмки S-018, план пересмотреть.

**Как сейчас.** [xpj.py](../logic2mpc/adapters/xpj.py): `write_project` берёт встроенный `logic2mpc/template/template.xpj` (копия `Spike4 A.xpj`, MPC-020: 1 драм-трек, 8 Submix, 4 Return, 16 Out). Первый трек `Drum 001` через `rename_first_track` становится пустым `HANDS`, `clear_pads` чистит пэды, `data["samples"]` обнуляется. Каждая группа плана получает копию HANDS, вставленную перед служебными треками (`insert_track`, MPC-023). Из того же файла берутся запись сэмпла (`data["samples"][0]`), нота (`note_template`), пустой клип (`clips[0]`) и основа секвенций (`sequences[0]`). Привязка к HANDS: константа `HANDS`, `rename_first_track`, тесты `test_build_hands_is_first_and_empty`, `test_overview_lists_tracks_with_hands_first_and_empty`, проверка `[:2] == ["HANDS", "Drums"]` в `tests/test_overview.py`, CLAUDE.md (образ результата п. 5, «Вне первой версии»).

**Что подтверждено.** Сборка из шаблона правкой JSON (MPC-007). Вставка трека перед служебными и клип в каждой секвенции (MPC-023). Копия программы работает, в том числе взятая из другого проекта (спайк 8, T05–T07). Запись сэмпла (MPC-069).

**Что не подтверждено.** Сборка проекта или трека с нуля: в `schema.tsv` большинство полей `unknown`, какие поля обязательны, неизвестно (container.md). Удаление трека. Совместимость шаблона другой версии прошивки (versions.md: «не проверялись»). Смысл `audioRoute` (MPC-041, `hypothesis`) и Mute (MPC-040, `open`): стори их не меняет.

**Поправка по ответу пользователя.** Донорский проект не нужен: структуру можно описать, а копия приносит скрытое состояние. Пример: копия трека унесла `recordArm` true на все треки, MPC-R-003, исправлено точечной правкой вне стори (`track["recordArm"] = False`, тест `test_build_arms_only_current_track`). Описание должно задавать каждое поле явно, а не наследовать его.

**Что можно описать уже сейчас.** `schema.tsv` содержит все пути из 33 файлов с типом и наблюдавшимися значениями: `tracks[]` (997 путей, из них `drum` 387), клипы и события в `sequences[]` (141), запись сэмпла в `samples[]`. Для поля с одним наблюдавшимся значением в описание ставится оно, для поля с несколькими решение записывается отдельно со ссылкой на факт. Что поле нужно Live 2, подтверждает только открытие на железе, поэтому описание сверяется со схемой тестом, а смысл неизвестных полей остаётся `unknown`.

**Что описать нельзя без нового спайка.** Корень проекта (`mixer` 681 путь, `assignable*`, `songs`, `scene`) и служебные треки Out, Submix, Return: известны только по копиям, обязательность полей не проверялась. Их по-прежнему даёт шаблон пользователя: роутинг и предустановленные треки в нём и лежат, как в исходной стори.

### Вопросы

- [x] Откуда брать драм-трек: из описания в коде, донорского проекта нет
- [x] Пустые треки шаблона остаются, треки групп добавляются после них перед служебными
- [x] Предустановленные треки никогда не меняются, каким бы ни было их содержимое
- [x] Проекта по умолчанию нет. Без шаблона экспорт отказывает. Сборка корня проекта и служебных треков с нуля вынесена в следующую стори со спайком

### Принято при анализе, подтвердить при `/approve`

- Секвенции шаблона заменяются секвенциями по секциям, как сейчас: ноты в клипах предустановленных треков в них не переходят. Сам трек (программа, пэды, маршрут, Mute) не трогается.
- `data["samples"]` шаблона не обнуляется, сэмплы групп добавляются.
- Имя группы, совпавшее с именем трека шаблона (после транслитерации), отказывает сборку до записи: клипы ищутся по имени трека, MPC-024.
- Темп плана записывается в `masterTempo` и секвенции, остальные настройки шаблона не меняются.
- Новые треки получают `recordArm` false всегда, `currentTrackIndex` и стрелки шаблона не меняются. Роутинг новых треков: основной выход, как наблюдалось в Rataklang (MPC-041, `hypothesis`).
- Версия прошивки шаблона не проверяется.

## План

1. **Описание формата в коде.** Модуль `logic2mpc/adapters/xpj_spec.py`: функции `drum_track`, `drum_pad`, `sample_entry`, `clip`, `note_event`, `sequence`. Каждое поле записано явно, рядом номер факта MPC или пометка `observed` для неизвестного с константой из `schema.tsv`. Копирование объектов из проекта убирается. Размер пустого драм-трека 128 пэдов собирается циклом.
2. **Шаблон пользователя.** `write_project(plan, samples, out, name, template)`: путь обязателен. До записи шаблон проверяется: читается, есть служебные треки (тип ≥ 7), иначе `ValueError`. Донор и `logic2mpc/template/` удаляются, вместе с `HANDS`, `BASE_TRACK`, `rename_first_track`, `clear_pads`, `note_template`.
3. **Сборка.** Трек группы создаётся из описания и вставляется `insert_track` перед служебными, клип добавляется в секвенции. Предустановленные треки и их программы не читаются и не пишутся. `data["samples"]` дополняется. Точечная правка `recordArm` заменяется полем в описании.
4. **Проверки.** `check` дополняется коллизией имён групп с треками шаблона.
5. **Вызовы.** `app.build(version, out, name, template)`, CLI `build --template`, `ui --template`, поле шаблона в интерфейсе экспорта ([web.py](../logic2mpc/adapters/web.py), [index.html](../logic2mpc/web/index.html)). В план шаблон не пишется.
6. **Документы.** CLAUDE.md: п. 5 образа результата, «Вне первой версии», строка «Выход». Реквесты к базе по полям, где в описании выбрано значение без подтверждения.

Затрагиваются: `logic2mpc/adapters/xpj.py`, новый `logic2mpc/adapters/xpj_spec.py`, `logic2mpc/app.py`, `logic2mpc/__main__.py`, `logic2mpc/adapters/web.py`, `logic2mpc/web/index.html`, `tests/test_export.py`, `tests/test_overview.py`, `tests/test_session.py`, новая `tests/fixtures/template.xpj`, `CLAUDE.md`.

Не входит: корень проекта и служебные треки без шаблона (следующая стори со спайком), сопоставление группы с предустановленным треком по имени, подбор роутинга под шаблон, проверка версии прошивки, кейгруппа и плагин, перенос нот шаблона.

## Реквесты

Блоки формата с одной версии прошивки в шаблоне другой: kind `add`, `hypothesis`. Создаётся при разработке, номер выдаётся тогда.
