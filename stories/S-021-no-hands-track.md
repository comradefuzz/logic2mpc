## Стори

Экспорт не создаёт пустой трек HANDS: проект содержит только треки групп плана. Пустой трек для ручной игры пользователь при необходимости заводит на Live 2 сам.

## Анализ

**Как сейчас.** [xpj.py](../logic2mpc/adapters/xpj.py): `export_project` первым треком добавляет `HANDS` (пустой драм-трек, 128 пэдов без сэмплов, `recordArm` true), затем треки групп. Привязка к HANDS: константа `HANDS`, номер 0 в `drum_track`, список `titles`, проверка совпадения имён, клипы HANDS в каждой секвенции. В документах: CLAUDE.md (образ результата п. 5, «Вне первой версии»), контракт `docs/contracts/xpj-export.md`. В тестах: `test_build_hands_is_first_and_empty` (`tests/test_export.py`), HANDS в `tests/test_xpj_spec.py` и `tests/test_overview.py`.

**Что известно о формате.**
- Проект Live 2 с одним драм-треком открывается (`Empty.xpj`, кейсы Z и T).
- `recordArm` true значит, что игра на пэдах идёт в этот трек, Live 2 при сохранении оставляет true только у `currentTrackIndex` (MPC-111, MPC-104). Поэтому первый трек группы должен быть armed, иначе пэды молчат до выбора трека.
- Сборка без треков вообще (ни одной группы) на Live 2 не проверялась.

**Принято при анализе, подтвердить при `/approve`.**
- Первым треком проекта становится первая группа плана, `currentTrackIndex` 0 остаётся, `recordArm` true только у неё.
- План без групп отклоняется до записи (`ValueError` и `minItems` 1 в схеме): проект без треков не проверялся.
- Имя `HANDS` больше не зарезервировано: группа может так называться.
- Сквозной номер пэда (`номер трека * 128 + пэд`) и производные от него поля (`randomPlaySeed`, `sliceIncrementRngSeed`, цвет трека по кругу) считаются от нового номера трека: первая группа получает 0, а не 1. Байты проекта и цвета треков сдвигаются по определению, на звук и ноты это не влияет.
- [S-014](S-014-project-template.md) (шаблон) больше не упоминает удаление HANDS: оно сделано здесь.

## План

1. **Сборка.** В `export_project` убрать HANDS: константу, трек номер 0, запись в `titles`; `drum_track(number, ...)` получает `armed = number == 0` для первого трека группы. Проверка уникальности имён остаётся для групп. План без групп даёт `ValueError` до записи.
2. **Схема.** В `export-plan.schema.json` у `groups` `minItems` 1.
3. **Документы.** CLAUDE.md: п. 5 образа результата («первым создаётся первая группа»), «Вне первой версии». `docs/contracts/xpj-export.md`: состав проекта без HANDS.
4. **Тесты.** Существующие тесты, привязанные к HANDS, переписываются под новое поведение: первый трек это первая группа и он armed.

Затрагиваются: `logic2mpc/adapters/xpj.py`, `logic2mpc/spec/export-plan.schema.json`, `CLAUDE.md`, `docs/contracts/xpj-export.md`, `tests/test_export.py`, `tests/test_xpj_spec.py`, `tests/test_overview.py`.

Не входит: сборка поверх шаблона пользователя ([S-014](S-014-project-template.md)), цвета треков ([S-019](S-019-track-colours.md)), раскладка пэдов для ручной игры.
