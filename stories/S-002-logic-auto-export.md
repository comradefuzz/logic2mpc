## Стори

Спайк 2 из CLAUDE.md: автоэкспорт из Logic: можно ли запустить Export All Tracks скриптом, работает ли шаблон имён `NN_Имя__тег`.

## Анализ

Спайк 1 решил, что структура берётся из файла, а звук из экспорта. Значит, здесь нужно не только запустить экспорт, но и надёжно сопоставить каждый файл со строкой дорожки из `probe.py`.

### Что уже известно

- Logic Pro 10.8.1 объявляет поддержку AppleScript, но словарь `LogicSuite.sdef` содержит одну команду `renderPreview`. Команды экспорта в нём нет. Открытие проекта стандартными командами не проверялось.
- Значит, запуск возможен только через управление интерфейсом: System Events нажимает меню и заполняет диалог. Для этого нужно разрешение Accessibility, его выдаёт пользователь в настройках macOS.
- В чек-листе спайка 1 экспорт в Final Cut Pro XML сам создал файлы `CTRL_*_1.aif` на каждую дорожку и стек: AIFF, 48 кГц, 24 бита, все от начала проекта. Export All Tracks может вести себя иначе, это не проверялось.
- В реальных проектах имена дорожек повторяются: в Pyro три `GTR L`, два `Glitch`. По одному имени файл с дорожкой не сопоставить.

- Диалог экспорта на 10.8.1 (снимок пользователя). Поля: `Range` (показано `Trim Silence at File End`), `Save Format`, `Bit Depth`, `Multi-Output Software Instruments` (неактивно, `One File per Track`), `Bypass Effect Plug-ins`, `Include Audio Tail`, `Include Volume/Pan Automation`, `Include Tempo Information`, `Normalize`, `Add resulting files to Project Browser`.
- Шаблон имён собирается из элементов `Custom`, `Project Name`, `Track Name`, `Track Number`, `Bar Range`, `Time Range`, `Increment`, `Year`, `Month`, `Day`, `Hour`, `Minute`, `Second`. Номер дорожки есть.
- Шаблон перетаскивается мышью, поэтому скрипту его лучше не менять: задать один раз вручную и проверить, сохраняется ли он между экспортами.

### Что неясно

- Совпадает ли `Track Number` из диалога со строками `probe.py`: считаются ли заголовки стеков и с какого числа идёт отсчёт.
- Что значит `тег`. В CLAUDE.md он не определён. Шаблон задаётся один на весь экспорт, поэтому свой тег для каждой дорожки возможен только через её имя. При сопоставлении по номеру тег не нужен: способ экспорта хранится в Export Plan.
- Какие строки дают файл: заголовки стеков, MIDI-дорожки, пустые и выключенные дорожки.
- Как экспорт обрабатывает эффекты, фейдеры, хвосты и начало файла, и все ли файлы одной длины.
- Устойчиво ли управление интерфейсом: зависит ли от языка Logic, размера окна, всплывающих диалогов.

### Вопросы

Блокирующих вопросов нет. Решения по умолчанию: `тег` в имени не обязателен, сопоставление идёт по номеру, а скрипт проверяется только на контрольном проекте.

## План

Работаем только с контрольным проектом в `test-projects/`. Реальные проекты не экспортируем, поэтому время и надёжность на большом проекте этот спайк не покажет.

1. **Ручной эталон (делает пользователь).** Экспорт всех дорожек `Spike Control.logicx` в `test-projects/exports/all-tracks/`, чек-лист `spikes/logic_export/CHECKLIST.md`. Записать снимками или текстом все поля диалога и названия пунктов меню. Если номера дорожки в шаблоне нет, искать замену.
2. **Разбор результата.** Скрипт `spikes/logic_export/match.py`: сопоставить файлы со строками `probe.py`, вывести строки без файла и файлы без строки, формат, длину и начало звука относительно региона.
3. **Варианты.** На контрольном проекте проверить настройки, влияющие на сэмплы: эффекты, фейдеры, хвост, стеки, выключенная дорожка. Отдельно проверить повтор имён: две дорожки с одним именем. Глубина ровно такая, чтобы выбрать настройки для автоэкспорта.
4. **Автозапуск.** Скрипт `spikes/logic_export/export_all.applescript` через System Events открывает меню, заполняет диалог, ждёт конца. Разрешение Accessibility выдаёт пользователь, я его не меняю. Запуск только на открытом контрольном проекте.
5. **Вывод.** Раздел спайка 2 в `docs/spikes.md`: шаблон имён, настройки, что выгружается, надёжность скрипта. Решение: автозапуск, полуавтомат с ручным нажатием или ручной экспорт с проверкой результата приложением. Обновить шаблон имён в CLAUDE.md, если он меняется.

**Файлы:** `spikes/logic_export/CHECKLIST.md`, `spikes/logic_export/match.py`, `spikes/logic_export/export_all.applescript`, `docs/spikes.md`, `CLAUDE.md` (только шаблон имён).

**Не входит:** код продукта, MIDI-экспорт (спайк 3), нарезка сэмплов, анализ качества звука (спайк 5), сама Export Plan.

## Заметки по ходу

Первый экспорт `Spike Control.logicx` (WAVE, 24 бита, Normalize Off, `Trim Silence at File End`, шаблон `Track Number` + `_` + `Track Name`):

- Файлов 7 при 7 дорожках. `Track Number` равен номеру строки `probe.py` плюс один, заголовки стеков считаются. Stereo Out файла не даёт.
- Все файлы начинаются с начала проекта: старт звука совпал с началом региона до тысячной секунды у `CTRL_kick`, `CTRL_loop`, `CTRL_free`. У `CTRL_sub` разница 0,107 с, это первая нота на шестнадцатую позже начала региона.
- Заголовки стеков дают свои файлы со смешанным звуком: `CTRL_drums`, `CTRL_inner`, `CTRL_bass`. При нарезке их нельзя брать вместе с дочерними дорожками, иначе звук задвоится.
- Длина файлов разная, файл кончается вскоре после последнего звука.
- Accessibility не выдан: `osascript` получил отказ, скрипт автозапуска не запускался.

Варианты `Range`: `Trim Silence at File End`, `Export Cycle Range Only`, `Extend File Length to Project End`. Оставляем первый: начало у файлов общее, а лишняя тишина в конце не нужна.

Вариант на копии 3 (пользователь положил новый регион на такт 11, а не 12):

- Повтор имён: `07_CTRL_free` и `08_CTRL_free` различаются номером, старт звука совпал с регионом у обеих.
- Folder-стек файла не даёт, но занимает номер: `05` пропущен. Summing-стек файл даёт.
- Пустая дорожка `CTRL_empty` файла не даёт, номер `09` пропущен.
- Выключенная `CTRL_kick` экспортируется со звуком. В смесь стека она не входит: `CTRL_drums` теперь звучит только с 9,6 с. Mute дорожки `probe.py` пока не читает.
- Файлы отличаются служебными чанками даже при одинаковом звуке. Звук (`data`) совпал у `04` и `06`, отличается у `02`: старт `CTRL_kick` сдвинулся на 3 мс, причина не выяснялась. Сравнивались разные проекты, повторного экспорта не было.

Решение пользователя: автозапуск не проверяем. macOS не показала запрос разрешения, `osascript` получает отказ. Итог спайка: ручной экспорт с проверкой результата, скрипт остаётся непроверенным черновиком.

Отступления от плана: шаг с реальным проектом убран по просьбе пользователя. Шаг 3 выполнен частично: проверены стеки, Mute дорожки и повтор имён, а эффекты, фейдеры, хвост и другие `Range` не сравнивались. Названия пунктов меню не записаны. Автотестов нет.
