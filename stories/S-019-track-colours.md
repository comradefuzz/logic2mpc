## Стори

Экспорт красит собранный проект так, как красит его сам Live 2. Драм-треки получают разные цвета. Пэды внутри драм-трека красятся по дорожке Logic: фрагменты одной дорожки, то есть варианты её материала, получают один цвет, разные дорожки разные цвета. Сейчас все треки голубые, а пэды зелёные (цвет по умолчанию).

## Анализ

**Как сейчас.** [xpj_spec.py](../logic2mpc/adapters/xpj_spec.py) `drum_track` берёт `colour` из `logic2mpc/spec/track.json`: 8959 (0x0022FF, голубой), значение `Drum 001` из `Empty.xpj`. Цвета пэдов (`program.programPads.pads.valueN`) в описание не входят и остаются 0: Live 2 показывает такие заполненные пэды ярко-зелёными.

**Что известно о формате** (эталон Live 2 `Example Colours.xpj` и снимки экрана Pad Color, анализ [S-025](S-025-colours-reference.md), реквесты MPC-R-014 и MPC-R-015).
- `tracks[].colour` целое RGB. Новым драм-трекам Live 2 назначает цвет сам, по кругу из 21 значения: `55FF00`, `00FF80`, `00AAFF`, `5200FF`, `FF00FF`, `FF4400`, `E6FF00`, `11FF00`, `00FFC4`, `0066FF`, `6F00FF`, `FF00BB`, `FF8800`, `A2FF00`, `00FF33`, `00F7FF`, `0022FF`, `B200FF`, `FF0077`, `FF0000`, `FFD500`. Первый трек нового проекта `55FF00`, 22-й снова `55FF00`. Без поля `colour` трек голубой (T02, MPC-114).
- Цвет пэда хранится в `program.programPads.pads.valueN` (N 0–127), целое RGB, 0 цвет не задан. Палитра пэдов: 25 цветов, 21 из них круг цветов треков, ещё три цвета служебных треков и `29B574`.
- Пэд с сэмплом без цвета Live 2 показывает ярко-зелёным (наблюдение пользователя), пустой пэд при `UnusedPads` = dim приглушён.
- Режимы экрана Pad Color в файле: `PadsFollowTrackColour` (Follow Track), `Universal` и `universalPad` (ALL PADS), `Type` (PAD DISPLAY TYPE), `UnusedPads` (EMPTY PADS). В описании формата экспорта они из `Empty.xpj`: PAD (цвета пэдов по одному), SINGLE PAD, Bright->Velocity, Empty pads dim.
- Служебные треки красятся отдельно (Submix `FF6D17`, Return `ECEC24`, Out `A2A9AD`), экспорт их не создаёт.
- Не проверено на устройстве: что пэды показывают записанные в `pads.valueN` цвета, что номер N совпадает с номером пэда в экспорте (MPC-R-002), какое поле включает Follow Track (`programPads.PadsFollowTrackColour` или `tracks[].padsFollowTrackColour`), как выглядят пустые пэды без цвета. Принимает ли Live 2 значения вне палитры, неизвестно, поэтому используются только значения круга.

**Принято при анализе, подтвердить при `/approve`.**
- Цвета треков: трек номер n (с 0, по порядку треков проекта) получает `TRACK_PALETTE[n % 21]`, то есть те же цвета, что получил бы при создании треков на Live 2. При 22 и более треках цвета повторяются, как у Live 2, это не потеря.
- Цвета пэдов: внутри драм-трека каждой дорожке Logic (по порядку дорожек группы плана, как номера mute group в [S-024](S-024-variants-mute-group.md)) достаётся цвет `TRACK_PALETTE[m % 21]`, где m номер дорожки с нуля. Все экспортируемые фрагменты дорожки (без слитых и выключенных) красятся одним цветом. Дорожка с одним фрагментом тоже получает цвет. Пустые пэды (без сэмпла) остаются 0.
- Цвета пэдов берутся из того же круга Live 2, что цвета треков, по порядку дорожек; цвет пэда не привязан к цвету трека.
- Режимы Pad Color из `Empty.xpj` не меняются (PAD, SINGLE PAD, Bright->Velocity, Empty pads dim).
- Цвет не зависит от способа экспорта и кода группы (DR, BS и других). Клипы цвет не получают: в клипе `colour` 0 по умолчанию.
- Расчёт ведёт экспортёр по плану, схема плана и контракт входа не меняются.

## План

1. **Палитра.** В [xpj_spec.py](../logic2mpc/adapters/xpj_spec.py) константа `TRACK_PALETTE` из 21 значения в порядке круга Live 2. `drum_track(name, armed, colour)` задаёт цвет трека явно, `pad(...)` получает `colour` пэда и пишет его в `programPads.pads.value{index % 128}` трека. Описание в `docs/formats/mpc/export.tsv` (`fill.py`) ссылается на факты MPC-R-014 и MPC-R-015 после принятия через `/kb`.
2. **Сборка.** В `export_project` трек номер n получает `TRACK_PALETTE[n % 21]`. В каждом драм-треке функция `pad_colours(group)` возвращает цвет для каждого экспортируемого фрагмента по порядку дорожек Logic (тот же порядок, что у `mute_groups`), для пустых пэдов 0.
3. **Контракт и документы.** `docs/contracts/xpj-export.md`: строки про цвет трека (круг Live 2 по порядку треков) и цвет пэда (по дорожке Logic). Правило в `docs/analysis.md`: номер правила выбрать свободный при разработке.
4. **Приёмка.** Промежуточные экспорты для ручной проверки на Live 2, которые закрывают неопределённости анализа (см. «Ручные проверки»).

Затрагиваются: `logic2mpc/adapters/xpj_spec.py`, `logic2mpc/adapters/xpj.py`, `spikes/mpc_spec/fill.py`, `docs/formats/mpc/export.tsv`, `docs/contracts/xpj-export.md`, `docs/analysis.md`.

Не входит: выбор цвета пользователем и поле цвета в плане, цвет по способу экспорта или коду группы, значения вне круга, цвета служебных треков, режимы Pad Color кроме значений `Empty.xpj`.

## Тесты

### Автотесты

- [ ] Первые 21 трек проекта получают 21 разный цвет в порядке круга Live 2, первый `55FF00`, 22-й повторяет первый
- [ ] Фрагменты одной дорожки Logic получают один цвет пэда, разные дорожки группы разные цвета, цвета по порядку круга от 0 в каждом драм-треке
- [ ] Пустые пэды остаются 0; слитые и неэкспортируемые фрагменты не влияют на цвет дорожки; дорожка с одним фрагментом красится
- [ ] Ни одно значение `colour` трека и пэда вне `TRACK_PALETTE` не пишется; остальные поля пэдов, ноты и режимы Pad Color не меняются; существующие тесты экспорта проходят

### Ручные проверки

На приёмке допустимы промежуточные экспорты для ручной проверки: они закрывают неопределённости анализа, результаты оформляются реквестами. Список проверок:

- [ ] Elated из плана v15 (группы как в reference): у треков разные цвета в порядке круга Live 2, у пэдов внутри трека цвета по дорожкам Logic, варианты одной дорожки одного цвета (например, четыре пэда `LD Saw Harm`), пустые пэды без цвета, звук и ноты как раньше
- [ ] Промежуточный экспорт 1: тот же проект с цветами пэдов, записанными в `programPads.pads.valueN`, проверить совпадение номера пэда в файле с номером на экране (`B 01` это пэд 16, MPC-R-002)
- [ ] Промежуточный экспорт 2: тот же проект с `programPads.PadsFollowTrackColour.value0` true, и отдельно с `tracks[].padsFollowTrackColour` true: какое поле включает Follow Track (пэды берут цвет трека, заполненные ярко, пустые приглушены)
- [ ] Промежуточный экспорт 3: пустые пэды без цвета: как выглядят при EMPTY PADS = dim, нужно ли красить их (решение по результату)
