## Стори

Экспорт задаёт цвета собранного проекта. Драм-треки красятся так же, как красит новые треки сам Live 2, то есть получают разные цвета. Пэды Live 2 сам не красит: по умолчанию заполненный пэд зелёный, остальные цвета возможны только вручную. Поэтому раскраска пэдов это решение проекта, а не поведение Live 2: внутри драм-трека пэды красятся по дорожке Logic, фрагменты одной дорожки, то есть варианты её материала, получают один цвет, разные дорожки разные цвета. Сейчас все треки голубые, а пэды зелёные.

## Анализ

**Как сейчас.** [xpj_spec.py](../logic2mpc/adapters/xpj_spec.py) `drum_track` берёт `colour` из `logic2mpc/spec/track.json`: 8959 (0x0022FF, голубой), значение `Drum 001` из `Empty.xpj`. Режим Pad Color в описании из `Empty.xpj`: `Universal` true (ALL PADS) при `universalPad` 0x00FF00. Поэтому Live 2 показывает все пэды ярко-зелёными, а `pads.valueN` (цвета пэдов по одному) остаются 0 и в этом режиме не используются.

**Что известно о формате** (эталон Live 2 `Example Colours.xpj` и снимки экрана Pad Color, анализ [S-025](S-025-colours-reference.md), реквесты MPC-R-014 и MPC-R-015).
- `tracks[].colour` целое RGB. Новым драм-трекам Live 2 назначает цвет сам, по кругу из 21 значения: `55FF00`, `00FF80`, `00AAFF`, `5200FF`, `FF00FF`, `FF4400`, `E6FF00`, `11FF00`, `00FFC4`, `0066FF`, `6F00FF`, `FF00BB`, `FF8800`, `A2FF00`, `00FF33`, `00F7FF`, `0022FF`, `B200FF`, `FF0077`, `FF0000`, `FFD500`. Первый трек нового проекта `55FF00`, 22-й снова `55FF00`. Без поля `colour` трек голубой (T02, MPC-114).
- Цвет пэда хранится в `program.programPads.pads.valueN` (N 0–127), целое RGB, 0 цвет не задан. Палитра пэдов: 25 цветов, 21 из них круг цветов треков, ещё три цвета служебных треков и `29B574`.
- Live 2 пэды сам не красит: пэд с сэмплом без цвета он показывает ярко-зелёным (наблюдение пользователя), пустой пэд при `UnusedPads` = dim приглушён, любой другой цвет пэда ставится только вручную (функция Pad Color).
- Режимы экрана Pad Color в файле: `PadsFollowTrackColour` (Follow Track), `Universal` и `universalPad` (SINGLE PAD / ALL PADS), `Type` (PAD DISPLAY TYPE), `UnusedPads` (EMPTY PADS). В `Empty.xpj` и у новых треков `Universal` true (ALL PADS, один цвет `universalPad` на все пэды, по умолчанию зелёный), `PadsFollowTrackColour` false, Type 5 (Bright->Velocity), UnusedPads 1 (dim). В эталоне у первого трека `Universal` false: пользователь переключил в SINGLE PAD, чтобы красить пэды по одному.
- Служебные треки красятся отдельно (Submix `FF6D17`, Return `ECEC24`, Out `A2A9AD`), экспорт их не создаёт.
- Не проверено: как выглядят пэды без цвета в режиме SINGLE PAD (в эталоне такие пэды у первого трека, но не заполненные). Формат записи цвета пэда (`pads.valueN`, индекс N как номер пэда) и переключение режима (`Universal` false) подтверждены эталоном, отдельной проверки не требуют.

**Принято при анализе, подтвердить при `/approve`.**
- Цвета треков: трек номер n (с 0, по порядку треков проекта) получает `TRACK_PALETTE[n % 21]`, то есть те же цвета, что получил бы при создании треков на Live 2. При 22 и более треках цвета повторяются, как у Live 2, это не потеря.
- Цвета пэдов (решение проекта, не поведение Live 2, который красит пэды только вручную): внутри драм-трека каждой дорожке Logic (по порядку дорожек группы плана, как номера mute group в [S-024](S-024-variants-mute-group.md)) достаётся цвет `TRACK_PALETTE[m % 21]`, где m номер дорожки с нуля. Все экспортируемые фрагменты дорожки (без слитых и выключенных) красятся одним цветом. Дорожка с одним фрагментом тоже получает цвет. Пустые пэды (без сэмпла) остаются 0.
- Цвета пэдов берутся из того же круга Live 2, что цвета треков, по порядку дорожек; цвет пэда не привязан к цвету трека.
- Чтобы цвета пэдов по одному действовали, экспорт выставляет `Universal` false (SINGLE PAD) у каждого драм-трека. Остальные режимы Pad Color (`Type`, `UnusedPads`, `PadsFollowTrackColour`, `universalPad`) остаются как в `Empty.xpj`.
- Цвет не зависит от способа экспорта и кода группы (DR, BS и других). Клипы цвет не получают: в клипе `colour` 0 по умолчанию.
- Расчёт ведёт экспортёр по плану, схема плана и контракт входа не меняются.

## План

1. **Палитра.** В [xpj_spec.py](../logic2mpc/adapters/xpj_spec.py) константа `TRACK_PALETTE` из 21 значения в порядке круга Live 2. `drum_track(name, armed, colour)` задаёт цвет трека явно, `pad(...)` получает `colour` пэда и пишет его в `programPads.pads.value{index % 128}` трека; `Universal.value0` ставится false. Описание в `docs/formats/mpc/export.tsv` (`fill.py`) ссылается на факты MPC-R-014 и MPC-R-015 после принятия через `/kb`.
2. **Сборка.** В `export_project` трек номер n получает `TRACK_PALETTE[n % 21]`. В каждом драм-треке функция `pad_colours(group)` возвращает цвет для каждого экспортируемого фрагмента по порядку дорожек Logic (тот же порядок, что у `mute_groups`), для пустых пэдов 0.
3. **Контракт и документы.** `docs/contracts/xpj-export.md`: строки про цвет трека (круг Live 2 по порядку треков) и цвет пэда (по дорожке Logic). Правило в `docs/analysis.md`: номер правила выбрать свободный при разработке.
4. **Приёмка.** Проверочный экспорт для ручной проверки на Live 2 (см. «Ручные проверки»).

Затрагиваются: `logic2mpc/adapters/xpj_spec.py`, `logic2mpc/adapters/xpj.py`, `spikes/mpc_spec/fill.py`, `docs/formats/mpc/export.tsv`, `docs/contracts/xpj-export.md`, `docs/analysis.md`.

Не входит: выбор цвета пользователем и поле цвета в плане, цвет по способу экспорта или коду группы, цвета служебных треков, режимы Pad Color кроме `Universal`.

### Ручные проверки

На приёмке допустимы промежуточные экспорты для ручной проверки, закрывающие неопределённости анализа. Здесь неопределённость одна (вид пэдов без цвета), её закрывает сам проверочный экспорт.

**Чеклист проверки на Live 2.** Проект `test-projects/mpc/s019/Elated S019.xpj` вместе с папкой `Elated S019_[ProjectData]` скопировать на SD. Номера и буквы пэдов ниже даны по нумерации экрана (A 01 это нижний левый пэд банка A, B 01 первый пэд банка B, MPC-R-002); номер N пэда в файле это `A 01` = 0, `B 01` = 16.

**1. Открытие.**
- [ ] Проект открывается без вылета, 8 драм-треков: HANDS, Synth, Drums, Bass, Lead, FX, Keys, Saw Harm

**2. Цвета треков** (экран выбора трека или Track View). Ожидаемый порядок круга Live 2:

- Тесты стори лежат в `story_tests/S-019/test_colours.py` (8 тестов). `conftest.py` не требует область для `story_tests/`.

Исправлено замечание об оформлении: в тесты стори добавлена ссылка на AN-072.

При `/accept` в общий набор перейдут два теста (область build): `test_tracks_of_a_built_project_follow_the_circle` вместе с проверкой круга и `test_pads_of_one_logic_track_share_a_colour_and_tracks_differ` с проверками слитых и пустых пэдов (по разделу «Тестирование»).
