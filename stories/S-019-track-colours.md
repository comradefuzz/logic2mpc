## Стори

Треки собранного проекта MPC получают разные цвета, по цвету треки группы отличаются от соседей. Сейчас после экспорта все треки голубые.

## Анализ

**Как сейчас.** [xpj_spec.py](../logic2mpc/adapters/xpj_spec.py) `drum_track` берёт `colour` из `logic2mpc/spec/track.json`: 8959 (0x0022FF, голубой), это значение `Drum 001` из `Empty.xpj`. Его получают все треки. Раньше, при копировании донора, было то же самое.

**Что известно о формате** (эталон Live 2 `Example Colours.xpj`, анализ [S-025](S-025-colours-reference.md), реквест MPC-R-014).
- `tracks[].colour` целое RGB. Новым драм-трекам Live 2 назначает цвет сам, по кругу из 21 значения: `55FF00`, `00FF80`, `00AAFF`, `5200FF`, `FF00FF`, `FF4400`, `E6FF00`, `11FF00`, `00FFC4`, `0066FF`, `6F00FF`, `FF00BB`, `FF8800`, `A2FF00`, `00FF33`, `00F7FF`, `0022FF`, `B200FF`, `FF0077`, `FF0000`, `FFD500`. Первый трек нового проекта `55FF00`, 22-й снова `55FF00`.
- Без поля `colour` трек голубой (T02, MPC-114): это `0022FF`, 17-й цвет круга.
- Служебные треки красятся отдельно (Submix `FF6D17`, Return `ECEC24`, Out `A2A9AD`) и сюда не входят: экспорт их не создаёт.
- `padsFollowTrackColour` везде false: пэды цвет трека не наследуют, их цвета в стори не трогаются.
- Принимает ли Live 2 значения вне круга, по эталону не видно, поэтому используется только круг.

**Принято при анализе, подтвердить при `/approve`.**
- Цвета задаются экспортёром по порядку треков проекта, без полей в плане: выбор цвета пользователем это отдельная стори.
- Цвет трека номер n (с 0) это `PALETTE[n % 21]` в порядке круга Live 2, то есть проект получает те же цвета, что получил бы при создании треков на самом Live 2. При 22 и более треках цвета повторяются, как у Live 2, это не потеря и в отчёт не пишется.
- Цвет не зависит от способа экспорта и кода группы (DR, BS и других).
- Клипы и пэды цвет трека не получают: в клипе `colour` 0 по умолчанию, пэды цвет трека не наследуют (раскраска пэдов отдельная стори).

## План

1. **Палитра.** В [xpj_spec.py](../logic2mpc/adapters/xpj_spec.py) константа `TRACK_PALETTE` из 21 значения в порядке круга Live 2 и `drum_track(name, armed, colour)`: `colour` задаётся явно. Описание в `docs/formats/mpc/export.tsv` (`fill.py`) ссылается на факт MPC-R-014 после его принятия через `/kb`.
2. **Сборка.** В `export_project` трек номер n (с 0, по порядку треков проекта) получает `TRACK_PALETTE[n % 21]`.
3. **Контракт.** В `docs/contracts/xpj-export.md` строка: цвет трека задаётся порядком треков по кругу Live 2, вход схемы не меняется.

Затрагиваются: `logic2mpc/adapters/xpj_spec.py`, `logic2mpc/adapters/xpj.py`, `spikes/mpc_spec/fill.py` (текст решения), `docs/formats/mpc/export.tsv`, `docs/contracts/xpj-export.md`.

Не входит: выбор цвета пользователем и поле цвета в плане, цвет по способу экспорта или коду группы, цвета пэдов и клипов, значения вне круга, цвета служебных треков.
