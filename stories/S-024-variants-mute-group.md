## Стори

Образцы одной дорожки плана, то есть варианты её материала, должны звучать как один голос: запуск одного обрывает остальные. Для этого экспорт задаёт им общую mute group на пэдах драм-программы.

## Анализ

**Как сейчас.** Все пэды получают `whichMuteGroup` 0 (нет группы): [pad.json](../logic2mpc/spec/pad.json) из `Empty.xpj`. Образцы одной дорожки (например, четыре варианта `LD Saw Harm` или два варианта `Bass Oliver`) лежат на разных пэдах и не обрывают друг друга. В Logic они один голос: регионы одной дорожки не звучат одновременно, следующий регион обрывает предыдущий.

**Что известно о формате.** `whichMuteGroup` это поле пэда драм-программы: на Live 2 значение 1 у двух пэдов даёт Mute Group 1, и один пэд глушит другой (кейс P06, MPC-115). В образцах значения 0, 1, 2. Поля `muteTargets` (явные цели) в образцах всегда 0, смысл не проверялся, экспорт их не использует.

**Данные Elated (план v15).** Дорожек с двумя и более экспортируемыми образцами 10: Drums 3 (`shs_roam_breaks` 4 образца, `Fill JaBouncy` 2, `Fill Long` 2), Bass 2 (`Bass Oliver` 2, `Normal Reese` 3), Synth 3 (`LD Saw Harm` 4, `Fire Glow` 2, `ZEN_STR` 3), Lead 1, FX 1. Больше всего таких дорожек в одной программе: 3. Mute group действует внутри драм-трека (программы): в нём 32 группы для пэдов, а сам драм-трек собран из фрагментов нескольких дорожек Logic. Нумерация начинается заново в каждом драм-треке (группе плана).

**Принято при анализе, подтвердить при `/approve`.**
- Группу получают фрагменты одной дорожки Logic, если после правок плана их осталось два и больше (слитые в один и выключенные не считаются). Фрагменты разных дорожек Logic друг друга не глушат. Дорожка с одним образцом остаётся с группой 0.
- Номера групп идут по порядку дорожек группы плана: первая дорожка с вариантами получает 1, вторая 2 и так далее.
- Режим пэда (Note On и One Shot, S-017), полифония и прочие поля пэда не меняются.
- Расчёт ведёт экспортёр по плану, схема плана и контракт входа не меняются.
- Доступно 32 mute group в программе (ответ пользователя, реквест MPC-R-013, `hypothesis` до проверки на устройстве). Если дорожек с вариантами в одной группе плана больше 32, лишние остаются без группы и попадают в потери.
- Группа задаётся всем образцам дорожки (ответ пользователя).

## План

1. **Правило.** `docs/analysis.md`: AN-068 уже занят режимом пэда, новое AN-069 «Mute group»: образцы одной дорожки плана получают общую группу, нумерация по дорожкам группы плана от 1 до 32, дорожка с одним образцом без группы. Статус `гипотеза`, запись в «Расхождения» до приведения кода.
2. **Тесты до кода.** `tests/test_xpj_spec.py` на синтетическом плане: образцы одной дорожки получают общую группу, разные дорожки разные группы; дорожка с одним образцом получает 0; нумерация начинается заново в каждой группе плана; слитые и неэкспортируемые образцы не считаются; 33-я дорожка с вариантами остаётся без группы и попадает в потери; остальные поля пэдов и ноты не меняются; сборка детерминирована.
3. **Код.** `xpj_spec.pad(..., mute_group=0)` пишет `whichMuteGroup`. `xpj.export_project`: функция `mute_groups(group)` возвращает номер группы для каждого экспортируемого образца по дорожкам группы плана, результат передаётся в `drum_track`. Потеря «не хватило mute group» при более чем 32 дорожках в группе.
4. **Реестр и контракт.** `fill.py` (текст решения для `whichMuteGroup`), `export.tsv`, `docs/contracts/xpj-export.md` (строка про mute group и потерю).
5. **Данные.** Пересобрать Elated. Драм-трек Drums собран из 20 дорожек Logic, из них три дали несколько фрагментов: пэды `shs_roam_breaks` (4 фрагмента) получают mute group 1, `Fill JaBouncy` (2) группу 2, `Fill Long` (2) группу 3. Пэды остальных 17 дорожек Drums (по одному фрагменту) остаются в группе 0 и ничего не глушат. В Synth аналогично три дорожки (`LD Saw Harm`, `Fire Glow`, `ZEN_STR`) получают группы 1, 2, 3, в Bass две (`Bass Oliver`, `Normal Reese`) группы 1 и 2, в Lead и FX по одной дорожке получают группу 1, в Keys групп нет. Номера считаются внутри каждого драм-трека и между треками не связаны.

Затрагиваются: `docs/analysis.md`, `logic2mpc/adapters/xpj_spec.py`, `logic2mpc/adapters/xpj.py`, `spikes/mpc_spec/fill.py`, `docs/formats/mpc/export.tsv`, `docs/contracts/xpj-export.md`, `tests/test_xpj_spec.py`.

Не входит: `muteTargets`, mute group для пэдов разных дорожек, выбор групп пользователем, режим пэда (S-017) и полифония.
