## Стори

Установить по эталонному проекту `Example Colours.xpj`, сохранённому Live 2, как формат хранит цвета драм-треков и пэдов: откуда берутся цвета при автоназначении, какая палитра доступна для пэдов, где пэд хранит цвет. Результат нужен экспорту, чтобы красить треки и пэды теми же цветами, что использует сам Live 2.

## Анализ

**Эталон.** `test-projects/reference/Example Colours.xpj`: 64 драм-трека создано подряд (цвета выставились автоматически), 28 служебных треков; у первого трека пэды покрашены вручную всеми цветами функции PadColors.

**Цвета треков** (`tracks[].colour`, целое RGB, MPC-R-014).
- Автоназначение идёт по кругу из 21 цвета: `55FF00`, `00FF80`, `00AAFF`, `5200FF`, `FF00FF`, `FF4400`, `E6FF00`, `11FF00`, `00FFC4`, `0066FF`, `6F00FF`, `FF00BB`, `FF8800`, `A2FF00`, `00FF33`, `00F7FF`, `0022FF`, `B200FF`, `FF0077`, `FF0000`, `FFD500`. Drum 022 и Drum 043 снова `55FF00`, Drum 064 тоже.
- Служебные треки: Submix `FF6D17`, Return `ECEC24`, Out `A2A9AD`, у всех одного вида одинаково.
- `padsFollowTrackColour` false у всех 92 треков: цвет пэдов от цвета трека не зависит.
- Старые образцы (Empty, Rataklang, Elated) содержат подмножество тех же значений. Голубой `0022FF` по умолчанию (MPC-114) это 17-й цвет круга.

**Цвета пэдов** (MPC-R-015).
- Хранятся в `program.programPads.pads.valueN`, N это номер пэда 0–127, значение RGB, 0 цвет не задан.
- Палитра PadColors из 25 цветов, в порядке, в котором пользователь красил пэды 0–24: `FF0000`, `FF6D17`, `FF4400`, `FF8800`, `ECEC24`, `FFD500`, `E6FF00`, `A2FF00`, `55FF00`, `11FF00`, `00FF33`, `00FF80`, `00FFC4`, `00F7FF`, `00AAFF`, `0066FF`, `A2A9AD`, `0022FF`, `5200FF`, `6F00FF`, `B200FF`, `FF00FF`, `FF00BB`, `FF0077`, `29B574`.
- 21 цвет совпадает с кругом цветов треков, три (`FF6D17`, `ECEC24`, `A2A9AD`) это цвета служебных треков, `29B574` встречается только у пэдов.
- У новых треков все 128 пэдов 0, цвет в файле не записан. Наблюдение пользователя на Live 2: пэд с сэмплом и незаданным цветом показывается ярко-зелёным, и это совпадает с `universalPad` 0x00FF00 у треков 2–64, то есть зелёный, вероятно, цвет по умолчанию. Функция Pad Color сбрасывает цвета пэдов и задаёт их заново по своим настройкам.
- Ключи `programPads` соответствуют экрану Pad Color (четыре снимка экрана приложены пользователем, MPC-R-015): `Type` это PAD DISPLAY TYPE (в эталоне 5, шестой пункт списка Off, Classic Velocity, Fixed, Off->Velocity, Dim->Velocity, Bright->Velocity), `UnusedPads` это EMPTY PADS (1, пункт «dim», список off, dim, normal), `Universal` это переключатель SINGLE PAD / ALL PADS (false, SINGLE PAD), `universalPad` это цвет режима ALL PADS, `PadsFollowTrackColour.value0` это режим Follow Track. Соответствие выведено по значениям эталона, прямой проверки сменой настройки не было.
- Режим Follow Track (со слов пользователя): цвета всех пэдов сбрасываются, пэды получают цвет трека, заполненный пэд ярко, пустой приглушён (при EMPTY PADS = dim). Если его включить, цвета пэдов по одному писать не нужно (S-019). Какое именно поле включает режим (это или `tracks[].padsFollowTrackColour`) не проверено.
- Не установлено: какое имя цвета палитры (например, `Canary`) какому коду соответствует, принимает ли Live 2 значения вне палитры.
- Нумерация пэдов по подписям экрана: банк B это B 01–B 16 с B 01 слева внизу, согласуется с MPC-R-002 (пэды файла 16–31).

**Что это значит для проекта.**
- [S-019](S-019-track-colours.md) (цвета треков) разблокируется: палитра известна, берём круг из 21 цвета в порядке Live 2, первый трек получает `55FF00`, как у самого Live 2.
- [S-020](S-020-track-colour-palette.md) (спайк палитры вручную) не нужен: ответ дан эталоном.
- Новая возможность, которой в проекте нет: красить пэды. Например, пэды одной дорожки Logic одним цветом из палитры пэдов (согласуется с mute group, S-024). Это отдельная стори `feature`, она не входит в спайк.

## План

Код не меняется. Результат спайка:
1. Реквесты к базе знаний: MPC-R-014 (цвета треков) и MPC-R-015 (цвета пэдов), оформлены при анализе. Принимаются через `/kb`.
2. Журнал: раздел «Спайк: цвета треков и пэдов» в `docs/spikes.md` с выводами выше.
3. S-019: снять блокировку, переписать план под круг из 21 цвета (без догадок). S-020: закрыть как ненужную.
4. Предложить отдельную стори на цвета пэдов (не создаётся без решения пользователя).

Затрагиваются: `docs/spikes.md`, `docs/formats/mpc/requests/`, `stories/S-019*.md`, `stories/S-020*.md`.

Не входит: код экспорта, раскраска пэдов, проверка на устройстве принятия значений вне палитры.
