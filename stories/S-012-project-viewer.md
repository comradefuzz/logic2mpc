## Стори

отдельный экран интерфейса «просмотр проекта». После экспорта нужно показывать его. На нём читается информация из XPJ, показывается сводка:

- список треков (с возможностью развернуть и посмотреть раскладку пэдов)
- список секвенций
- количество сэмплов и общий размер проекта

## Анализ

**Что требуется.** Экран после сборки: читает собранный `.xpj` и папку `_[ProjectData]`, показывает то, что реально попадёт на Live 2, а не то, что было в плане. Это независимая проверка результата сборки.

**Что уже есть.** Адаптер `adapters/xpj.py` читает и пишет `.xpj` (`load`, `parse`), структура собранных проектов известна: треки с программами, пэды с `sampleFile`, секвенции с именем и длиной, список сэмплов. Экран строится в той же веб-части (S-011), `GET` ручки и страница.

**Границы знаний.** Читаются только поля, которые есть в `docs/formats/mpc/` как `confirmed` или `single-sample` без открытых реквестов (треки и программы, пэды, секвенции, сэмплы: MPC-027, MPC-082 и соседние записи). Точный перечень полей сверяется с `programs.md`, `project.md`, `samples.md` на этапе тестов, найденное расхождение оформляется реквестом сразу.

**Объём.** Только чтение и показ. Правок проекта нет. Прослушивание сэмплов проекта входит как удобство, ноты и секвенции не воспроизводятся. Открытие произвольного `.xpj` с диска не входит, показывается только проект, собранный в этой сессии (путь известен серверу).

## План

Порядок: правило в `docs/analysis.md` не нужно, это не анализ. Сначала тесты, потом код.

1. **Ядро `core/overview.py`, чистое.** Сводка из уже разобранного словаря проекта: треки (имя, тип, число заполненных пэдов), пэды (номер, банк, имя сэмпла), секвенции (имя, длина в тактах), число сэмплов. HANDS показывается как пустой трек.
2. **Адаптер.** `adapters/xpj.py` получает функцию чтения проекта в сводку, размеры берутся по файлам `_[ProjectData]` на диске. Отсутствующий файл сэмпла записывается в сводку как проблема (`Sample not found`, MPC-083).
3. **Сервер.** `GET /api/project` по проекту, собранному в сессии, `GET /api/project/audio?name=` для прослушивания сэмпла из `_[ProjectData]` (только имена из списка сэмплов проекта).
4. **Страница.** Экран «Проект» после «Собрать»: заголовок с путём, три числа (треков, секвенций, сэмплов, МБ), список треков с раскрытием и сеткой пэдов, список секвенций, кнопка «Назад к плану».
5. **Прогон на Elated.** Сборка из S-011, сверка сводки с планом: число пэдов по группам, 10 секвенций, 73 сэмпла.

Не входит: правка проекта, открытие чужих `.xpj`, воспроизведение секвенций, сравнение с планом, кейгруппы и плагинные треки.
