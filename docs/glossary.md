# Единый язык

Одно слово на одно понятие в CLAUDE.md, сторях, коде, базе форматов и разговоре. Новое слово сначала попадает сюда. В скобках: имя в коде или в файле формата, чтобы не путать с понятием.

## Мир Logic

| Термин | Что это |
|---|---|
| **Дорожка** | Track в Logic: имя, регионы, группа. Слово «трек» для Logic не используем |
| **Группа проекта** | Папка Track Stack в Logic (drums, bass): единица плана |
| **Регион** | Отрезок дорожки на таймлайне: MIDI-регион с нотами или аудиорегион |
| **Стем** | Экспортированное аудио дорожки целиком (WAV) |
| **Маркер** | Метка на таймлайне, из маркеров строятся секции |

## Наш мир (план)

| Термин | Что это |
|---|---|
| **План экспорта** (`Plan`) | Документ в файле: решения по группам, дорожкам и фрагментам, с происхождением (rule, llm, user) и уверенностью |
| **Группа** (`Group`) | Группа проекта в плане. Способ экспорта задаётся на ней, исключения на дорожках |
| **Способ экспорта** (`method`) | Драм-трек, кейгруппа или плагин |
| **Стратегия** | Правило, по которому дорожка режется на фрагменты. Всегда принимает решение сама |
| **Нарезка** (`Cut`) | Результат стратегии на дорожке: набор фрагментов. Нарезка это версия, отказ даёт новую |
| **Фрагмент** (`Piece`, `PlanPiece`) | Вырезанное из дорожки аудио, станет сэмплом. Не путать с регионом |
| **Вхождение** (`Occurrence`) | Место, где фрагмент звучит в песне: тик, усиление, длина недоигранного прохода |
| **Секция** (`Section`) | Часть песни между маркерами, станет секвенцией MPC |
| **Цикл** (`Cycle`) | Повторяющийся рисунок внутри дорожки, длина в тактах |
| **Решительность** | Один параметр анализа: сколько вариантов фрагмента оставить |
| **Уверенность** (`confidence`) | Оценка каждого решения отдельно |
| **Ваншот** | Фрагмент, который играется целиком от удара. Противоположность: длинный сэмпл в режиме Note On |
| **Потеря** | То, что перевод Logic→MPC сознательно отбросил, попадает в отчёт |

## Мир MPC (Live 2)

| Термин | Что это |
|---|---|
| **Проект MPC** (`.xpj`) | Файл проекта и папка `_[ProjectData]` с одним именем |
| **Трек** (`tracks[]`) | Дорожка MPC. Слово «трек» только для MPC |
| **Драм-трек** | Трек с драм-программой: 128 пэдов, на каждом пэде сэмпл |
| **MIDI-трек** | Трек без инструмента, только ноты (способ «плагин») |
| **Служебные треки** | Out, Submix, Return: создаёт сам Live 2, удалить нельзя, экспорт их не касается |
| **Шаблон** | Проект пользователя, в который экспорт добавляет треки (S-014, COULD) |
| **Программа** (`program`) | Инструмент трека: драм-программа, кейгруппа, плагин |
| **Пэд** (`instrument`) | Один из 128 пэдов драм-программы, у него слои (`layer`) |
| **Сэмпл** | Запись в пуле проекта (`samples[]`) и WAV на диске |
| **Секвенция** (`sequences[]`) | Раздел песни на таймлайне MPC. Соответствует секции плана |
| **Нота-событие** (`eventList.events[]`, тип 3) | Нота в гриде трека |
| **Клип** (`trackClipMaps[]`, «clip» в формате) | Контейнер нот одного трека внутри секвенции. **Это не Clip Launch** и не матрица клипов Live 3: запуска по сетке в экспорте нет. Где можно, пишем «ноты трека в секвенции», слово «клип» только при ссылке на поле файла |
| **Триггер пэда** (`triggerMode`) | 0 One Shot, 2 Note On |

## Процесс

| Термин | Что это |
|---|---|
| **Стори** | Единица работы: `stories/S-NNN-slug.md` |
| **Спайк** | Проверка неизвестного руками, результат в `docs/spikes.md` |
| **Кейс** | Один проект спайка 9, одно изменение исходного (`Z01`, `P04`) |
| **Раунд** | Заход на Live 2 с набором кейсов |
| **Реквест** | Предложение к базе форматов `MPC-R-NNN`, принимается через `/kb` |
| **Факт** | Запись базы форматов `MPC-NNN` со статусом |

## Запрещённые синонимы

- «Дорожка» для MPC и «трек» для Logic.
- «Клип» вместо «фрагмент» (фрагмент это аудио для сэмпла, клип это поле файла MPC).
- «Кусок», «лупа», «семпл», «сегмент» вместо «фрагмент» и «сэмпл».
- «Партия» только для музыкального материала дорожки (CLAUDE.md: «Партии не теряются»).
