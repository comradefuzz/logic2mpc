Предлагается записать как `single-sample`: драм-трек Live 2 открывается и работает без полей, которые во всех образцах постоянны (кейс T01), без `colour` (трек получает голубой цвет по умолчанию), без `program.mixable` (громкость трека и пэдов при этом работает). Выключенный `recordArm` у единственного драм-трека не мешает пэдам срабатывать. Как это ведёт себя при нескольких драм-треках, не проверялось, сопоставлять с MPC-111 надо по этому случаю. Образец один.
