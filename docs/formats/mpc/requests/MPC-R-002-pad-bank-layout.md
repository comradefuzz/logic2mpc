Предлагается записать как `hypothesis`: драм-программа делится на банки по 16 пэдов, записи `instruments[]` 0–15 это банк A, 16–31 банк B и так далее до H (128 записей, MPC-060). Внутри банка запись 0 это левый нижний пэд, номера идут слева направо и снизу вверх, как нумеруются пэды Live 2. Нота пэда задаётся `padNoteMap.noteForPad` (MPC-062), порядок нот по банкам не проверялся. Экран просмотра проекта (S-012) строит сетку по этому допущению, ручная проверка на Live 2 записана в стори.
