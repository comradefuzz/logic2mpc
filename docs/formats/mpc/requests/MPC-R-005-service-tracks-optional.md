Предлагается записать как `single-sample`: проект, из которого удалены служебные треки Out, Submix, Return (по отдельности или все вместе), открывается на Live 2 и звучит. Служебные треки для открытия не обязательны. Но Live 2 не пересоздаёт отсутствующие: после удаления Submix и Return их нет в MIX, и добавить их из интерфейса пользователь не нашёл. Проект без них функционально беднее шаблона, поэтому сборка без служебных треков допустима только как крайний случай.
