Предлагается записать как `single-sample`: цвет пэда драм-программы хранится в `tracks[].program.programPads.pads.valueN` (N от 0 до 127 по порядку пэдов), целое RGB 0xRRGGBB, 0 означает, что цвет пэду не задан. Пэд с сэмплом и незаданным цветом Live 2 показывает ярко-зелёным (наблюдение пользователя). Это совпадает с `universalPad` 0x00FF00 у треков Drum 002–064, возможно значение по умолчанию, но связь по файлу не доказана. Функция Pad Color на Live 2 сбрасывает цвета пэдов и задаёт их заново по настройкам функции (наблюдение пользователя). `programPads.PadsFollowTrackColour.value0` это режим Follow Track этой функции (наблюдение пользователя, по названию): при его выборе цвета всех пэдов сбрасываются и пэдам устанавливается цвет трека, заполненный пэд светится ярко, пустой приглушён; в эталоне он false. Как соотносится с `tracks[].padsFollowTrackColour` (тоже false везде) по файлу не видно. Палитра PadColors на Live 2 состоит из 25 цветов, в порядке, в котором пользователь красил пэды 0–24: 0xFF0000, 0xFF6D17, 0xFF4400, 0xFF8800, 0xECEC24, 0xFFD500, 0xE6FF00, 0xA2FF00, 0x55FF00, 0x11FF00, 0x00FF33, 0x00FF80, 0x00FFC4, 0x00F7FF, 0x00AAFF, 0x0066FF, 0xA2A9AD, 0x0022FF, 0x5200FF, 0x6F00FF, 0xB200FF, 0xFF00FF, 0xFF00BB, 0xFF0077, 0x29B574. Двадцать один из них это автоназначаемые цвета треков (MPC-R-014), ещё три (0xFF6D17, 0xECEC24, 0xA2A9AD) это цвета служебных треков, 0x29B574 встречается только у пэдов. Экран Pad Color Live 2 и ключи `programPads`, соответствие по значениям эталона (в эталоне у первого трека Type 5, UnusedPads 1, Universal false, у остальных треков и в `Empty.xpj` Universal true):
- `Type` это PAD DISPLAY TYPE. Список на экране: Off, Classic Velocity, Fixed, Off->Velocity, Dim->Velocity, Bright->Velocity (выбран). Значение 5 это шестой пункт по нулевому индексу, то есть Bright->Velocity.
- `UnusedPads` это EMPTY PADS. Список: Empty pads off, Empty pads dim (выбран), Empty pads normal. Значение 1 это второй пункт, dim. Это же объясняет «пустой приглушён» у режима Follow Track.
- `Universal` это переключатель SINGLE PAD / ALL PADS. У новых треков и в `Empty.xpj` он true (ALL PADS) при `universalPad` 0x00FF00: это объясняет, почему пэды по умолчанию зелёные. В `Example Colours.xpj` у первого трека он false (SINGLE PAD, выбран на снимке): пользователь переключил режим, чтобы красить пэды по одному, при этом `universalPad` у этого трека 0xFF0000. У остальных 63 треков эталона `Universal` true. Что в режиме ALL PADS `pads.valueN` игнорируются, по файлу не видно, это вывод из поведения (зелёный у всех пэдов при незаданном цвете).
- `PadsFollowTrackColour.value0` это вкладка FOLLOW TRACK (PAD при false).
- Палитра на экране: 24 цвета в шести рядах по четыре, затем зелёный (вероятно `29B574`) и клетка «без цвета» (значение 0). В режиме Follow Track экран показывает имя цвета трека (на снимке `Canary`), имена цветов палитры по снимкам не сопоставлены с кодами.
- Нумерация на снимках: банк B, подписи B 01–B 16, B 01 слева внизу, B 13–B 16 в верхнем ряду. Это согласуется с гипотезой MPC-R-002 (16 пэдов на банк, первый пэд слева внизу): пэды 16–31 файла это B 01–B 16, у эталона покрашены пэды 0–24, то есть A 01–A 16 и B 01–B 09.

Соответствие названий экрана значениям файла выведено по совпадению индексов и одному образцу, прямой проверки (смена настройки, сохранение, сравнение файлов) не было. Соответствие номера пэда физическому пэду и банку проверено только по подписям на экране.
