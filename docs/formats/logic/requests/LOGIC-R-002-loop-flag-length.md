LOGIC-047 неточен в двух местах.

1. Признак Loop это бит `0x200`, а не `0x1000`. В Elated 1 сочетания такие: `0x200` с `0x1000` 52 раза, `0x200` без `0x1000` 2 раза, `0x1000` без `0x200` ни разу. Оба случая без `0x1000` в экспорте звучат зацикленно. Смысл `0x1000` неизвестен.
2. `+0x1c` это полная длина региона с повторами, а не длина повторов сверх первого прохода. `HH Meat` на такте 17: 16 тактов, звук занимает такты 17–32. `Angry` на такте 57, длина региона 8, значение 16: звук до такта 73. Контрольный `RGN_loop`: начало 16.5, длина 2, значение 6, конец 22.5, это 3 прохода, а не 4.

Предлагается записать: Loop это `+0x0c` бит `0x200`, регион звучит от начала до начало плюс `+0x1c`, повторяясь с периодом своей длины.

Следствие для кода: `region_notes()` в `probe.py` считает `extra + length` и добавляет лишний проход.
