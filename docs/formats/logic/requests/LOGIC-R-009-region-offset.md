Смещение региона в аудиофайле хранится в `gRuA +0x06` как u32, в кадрах. Вместе с длиной `+0x16` и номером файла в размещении `+0x2C` оно задаёт кусок файла: регионы с одинаковой тройкой это один и тот же звук.

Эталон только внутренний: значения сходятся между собой на реальных дорожках, контрольного проекта с заданным смещением нет. Предлагается закрыть LOGIC-045 как `single-sample`, поле `+0x06` убрать из `unknown`. Это делает ненужным признак по имени из LOGIC-R-008.
