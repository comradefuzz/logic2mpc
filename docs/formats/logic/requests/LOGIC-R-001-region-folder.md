Папка регионов задаёт поведение своих дочерних регионов, и его надо учитывать при чтении.

Предлагается записать: размещение папки имеет собственные Mute (`+0x0c` бит 0), Loop и длину `qeSM`. Mute папки выключает все дочерние регионы, хотя их собственный бит 0 сброшен. Дочерний регион за длиной папки не звучит. Loop папки повторяет содержимое с периодом длины папки.

Пример: `kick_nerve`, папки на тактах 1 и 5 выключены, дочерние флаги чистые, в экспорте такты 1–8 пустые. Папка на такте 9 длиной 3.25 такта отрезает удары 12.25–12.75.

Сейчас `regions()` в `probe.py` читает только флаг дочернего региона и не применяет длину и Loop папки: для `kick_nerve` выходит 239 слышимых ударов вместо 320.
