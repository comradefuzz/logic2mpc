# Спайки

## Спайк 1. Что читается из проекта Logic

Стори [S-001](../stories/S-001-logic-project-read.md). Инструмент: `spikes/logic_read/probe.py`, контрольный проект: [CHECKLIST.md](../spikes/logic_read/CHECKLIST.md).

### Решение

Статус: принято в S-001. Контрольный проект сошёлся, деревья стеков Pyro и Elated пользователь сверил с экраном Logic.

**Структуру берём из файла, содержимое из экспорта.**

- Из `.logicx`: дорожки, стеки, начала регионов и их дорожки, основные значения проекта.
- Из MIDI-экспорта: ноты и длины MIDI-регионов, а также темп, размер и маркеры. Они есть и в файле, поэтому служат независимой сверкой.
- Из экспорта аудио (спайк 2): сами звуки.

Папочная структура читается из файла, поэтому спайку 2 не нужно восстанавливать её по именам.

### Риск

Высокий на горизонте обновлений Logic: формат недокументирован, а размер записей и номера схем менялись между версиями. Поэтому чтение привязывается к версии файла. На неизвестной версии чтение должно останавливаться с понятным сообщением, а не выдавать догадку. Перед поддержкой новой версии Logic контрольный проект пересобирается и сверяется заново. Если чтение сломается, запасной путь это структура из имён экспорта.

### Что читается из файла

Статусы: **сверено** значит совпало с эталоном контрольного проекта (`CHECKLIST.md`), **частично** значит есть оговорка, **не прочитано** значит не получено. Если не сказано иного, значения читаются на всех проектах из списка, но эталон есть только у контрольного.

| Поле | Где | Статус | Оговорка |
|---|---|---|---|
| Основной темп, размер, число дорожек | `MetaData.plist` | сверено | |
| Тональность, частота | `MetaData.plist` | частично | Значения читаются, эталона нет |
| Активная альтернатива | `ActiveVariant` в `ProjectInformation.plist` | сверено | В Pyro и Elated ключа нет, у них одна альтернатива |
| Разбор `ProjectData` на записи | заголовок записи | сверено | Все файлы пройдены до конца |
| Карта темпа | `qSvE` роли 3 | частично | На контроле верно. В MONTERO две таких записи и дубль точки, какая главная, не выяснено |
| Смены размера | `qSvE` роли 1 | сверено | |
| Маркеры и имена | `qSvE` + `qSxT` | сверено | |
| Порядок и имена дорожек | `karT` + `ivnE` | сверено | В списке на строку больше `NumberOfTracks`: это Stereo Out с типом строки 3, её надо отбрасывать |
| Вложенность стеков | `karT`, глубина `+0x0e` | сверено | На Pyro и Elated сверено с экраном Logic |
| Тип стека | `karT`, бит `0x40` в `+0x28` | частично | Один пример folder-стека. Во всех реальных проектах вышло summing, это не проверено. Значение `0xa0` встречается и у обычной дорожки: `Audio 74` в Pyro, поэтому заголовок определяется по вложенности |
| Имена и начала регионов, привязка к дорожке | список регионов | сверено | На реальных проектах у всех найденных регионов есть имя и дорожка, с экраном не сверено |
| Длина MIDI-региона | `qeSM +0x56`, тики | частично | На контроле верно, на реальных проектах часто мусор: Elated 121 из 122, Pyro 24 из 61. Смещение не подходит, брать длину из MIDI-экспорта |
| Длина аудиорегиона | `gRuA +0x16`, кадры исходника | частично | Не всегда равна длине на таймлайне: `RGN_free` 84 649 кадров на такт при ожидаемых 82 286, `RGN_loop` 169 248 за два такта при 164 571. Причина не выяснена |
| Папки регионов и take folders | вложенные списки | частично | Контрольный проект этого не содержит. Неактивные дубли помечаются на Pyro, с экраном не сверено |
| Track Alternatives | список `0xc0000` | не прочитано | В MONTERO 37 списков и 838 размещений вне основного обхода. Все они под записью с именем `Track Alternatives`, то есть, вероятно, неактивные версии дорожек. Если они важны, их надо читать отдельно, иначе партии можно потерять |
| Смещение региона внутри файла | неизвестно | не прочитано | Нужно, если резать сэмплы из исходников, а не из экспорта |

### Что дают экспорты

| Поле | MIDI | Final Cut Pro XML | AAF |
|---|---|---|---|
| Темп, размер, маркеры | есть, все значения совпали | нет | не найдено |
| Ноты и позиции MIDI-регионов | есть, аудиорегионов нет | нет | не найдено |
| Имена | регионы и дорожки | дорожки и стеки | не найдено |
| Стеки | нет | отдельные клипы без вложенности | не найдено |
| Аудио | нет | стемы с начала проекта, включая стеки | не разобрано |

- **MIDI:** формат 1, 480 PPQ, дорожка с темпом и маркерами плюс дорожки с нотами. На каждой два имени: регион в `FF 03` и дорожка в `FF 04`. Проверено только для случая «один регион на дорожку».
- **Final Cut Pro XML:** при экспорте Logic сам сделал по файлу `CTRL_*_1.aif` на дорожку и стек. Это касается спайка 2.
- **AAF:** в файле не нашлось строк с нашими именами, настоящим разборщиком он не открывался. Apple Loops в AAF не экспортируются: Logic пропустил два таких файла. Для проекта на лупах AAF не подходит.

### Чужие работы

- [LogicProFormatWriter](https://github.com/jonkubis/LogicProFormatWriter), MIT, спецификация снята на Logic 11.2.2. Подошли рамка записей, темп, размер, маркеры и поля размещений. Заголовки стеков, глубины и типа стека в ней нет, это найдено здесь. Имя в `qeSM` оказалось именем региона, а не дорожки.
- [logicx-analyzer](https://github.com/geoffmyers/logicx-analyzer) и [bravoh-daw](https://docs.rs/bravoh-daw): заявлен частичный разбор, код не проверялся.

Код этих проектов не запускался и не копировался.
